YANIMERI — UPDATED NO-INSTALL PROTOTYPE

HOW TO OPEN
1. Extract this ZIP.
2. Open the yanimeri folder.
3. Double-click index.html. Chrome or another browser should open it.

WHAT'S INCLUDED
- Red-and-white default theme with customizable accent/background colours and font choices.
- Profile picture upload, camera option, banner upload, and banner framing controls (horizontal position, vertical position, zoom).
- Feature suggestion box and the requested chatting-coming-soon page.
- First-visit demo onboarding: enter a display name/email, then choose one of the four companion characters.
- The chosen companion appears on the home page, floats gently, speaks in a bubble, and opens a small help menu.
- Companion pictures are referenced directly from the four Pinterest image URLs supplied by the user; they are not AI-generated.
- Discover uses Jikan/MyAnimeList as its primary paginated anime catalogue and Kitsu as an independent fallback if Jikan is unavailable. Search and Load more allow browsing many pages. Each poster URL comes from that anime’s database record; failed images are retried through an image proxy and then shown as an explicit unavailable placeholder (never a random generated icon).
- Existing library, episode/rating tracking, private diary and profile features are retained.

IMPORTANT LIMITATIONS
- This is a local prototype, not a published website or a multi-user service.
- The onboarding form is a local demo profile only. It does NOT create a real account or authenticate a user. Do not enter a real password; none is requested or stored. Real Google/email sign-in requires a secure backend.
- Diary entries, suggestions, profile images, companion choice and settings are saved only in this browser on this device. Suggestions are NOT sent to the owner.
- The online anime catalogue requires internet. It uses Jikan/MyAnimeList with Kitsu fallback, retries temporary rate limits, and is paginated; use Search and Load more rather than loading thousands of posters at once. No single public API can guarantee literally every anime ever made.
- Anime cover art comes from Jikan/MyAnimeList listings and is not a guarantee of official licensing or availability for commercial use.
- Companion images are embedded from the Pinterest links directly. Pinterest or the image host may block external embedding, so a link may fail to display. The CSS blend treatment can visually blend a light/white image background into the page, but it does NOT create a true transparent cutout. True background removal requires the image files or a permitted image-processing service.
- Real public posting, messaging, cloud sync, reporting/moderation and community safety controls need a backend before public launch.
- Uploaded profile images are limited to 1.2 MB each in this prototype to avoid filling browser storage.
- Use images you have permission to use when customizing your profile.
